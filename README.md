# MarketPulse 🚀

AI-powered market intelligence application.

## Features
- Real-time crypto prices (CoinGecko)
- Stock market data (Alpha Vantage)
- AI market analysis (LangChain + Gemini)
- JWT Authentication
- Dark purple/gold themed UI

## Tech Stack
- **Backend**: Python, FastAPI, MongoDB
- **AI**: LangChain + Gemini
- **Data**: CoinGecko + Alpha Vantage APIs
- **Frontend**: React
- **Auth**: bcrypt + JWT
